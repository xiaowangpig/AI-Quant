# AI-Quant — 股票 K线仪表盘

基于 Tushare Pro 数据 + ECharts 5 的 A 股可视化仪表盘。

## 📋 覆盖标的

| 标的 | 代码 | 板块 | 时间范围 | 交易日数 |
|------|------|------|----------|---------|
| **京东方A** | 000725.SZ | 深市主板 | 2025-06 ~ 2026-06 | 242天 |
| **中芯国际** | 688981.SH | 科创板 | 2025-06 ~ 2026-06 | 236天 |

## 📊 功能

- **K线图**：日K线 + MA5/MA20 均线
- **成交量图**：红涨绿跌柱状图
- **关键指标**：最新价、近1年高低、涨幅、日均成交量
- **数据表**：可切换查看每日详细交易数据
- **时间缩放**：底部滑块支持拖拽查看任意区间

## 🔧 技术栈

- 数据源：Tushare Pro HTTP API
- 可视化：ECharts 5
- 布局：响应式 HTML + CSS
- 数据获取：Python
