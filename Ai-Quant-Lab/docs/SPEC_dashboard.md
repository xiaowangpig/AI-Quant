# 技术指标交互计算工作台 — 产品设计文档

## 1. 产品概述

### 1.1 目标
构建一个纯前端的 HTML 交互工具，用户可以选择股票、调整技术指标参数，实时看到 K 线图 + 四个指标的动态计算结果。

### 1.2 核心用户旅程
```
选择股票 → 设置日期范围 → 查看价格图 → 切换指标标签 → 拖动参数滑块 → 图表即时重绘
```

### 1.3 技术约束
- 纯前端 HTML + CSS + JavaScript（无后端依赖）
- 数据通过预加载的 JSON/CSV 文件提供（或内嵌样本数据）
- 图表引擎：ECharts 5 (CDN 加载)
- 指标计算在浏览器端 JS 中完成

- 宽屏 (≥1200px): 左侧参数面板固定 320px，右侧图表自适应

- 窄屏 (<768px): 参数放到模态抽屉中

## 3. 功能模块

### 3.1 股票选择器

| 功能 | 说明 |
|------|------|
| 下拉菜单 | 预置 6-8 只典型股票（覆盖不同风格） |
| 搜索过滤 | 输入名称或代码快速定位 |
| 自定义代码 | 支持手动输入 ts_code（如 600519.SH） |

预置股票池:

| 京东方A | 000725.SZ | 深市 | 面板制造 |
| 比亚迪 | 002594.SZ | 深市 | 新能源 |
| 长江电力 | 600900.SH | 沪市 | 高股息、公用事业 |

### 3.2 日期范围
- 快捷按钮: 近1月 / 近3月 / 近6月 / 近1年 / 全部
- 自定义: 两个日期输入框 (YYYY-MM-DD)

### 3.3 参数面板（左侧）

每个指标独立成卡片，滑块+数值输入联动。

#### RSI 参数
| 参数 | 默认值 | 范围 | 步长 |
|------|--------|------|------|
| 周期 Period | 14 | 2 ~ 50 | 1 |
| 超买线 | 70 | 50 ~ 95 | 1 |
| 超卖线 | 30 | 5 ~ 50 | 1 |

#### MACD 参数
| 参数 | 默认值 | 范围 | 步长 |
|------|--------|------|------|
| 快线周期 Fast | 12 | 5 ~ 50 | 1 |
| 慢线周期 Slow | 26 | 10 ~ 100 | 1 |
| 信号周期 Signal | 9 | 3 ~ 30 | 1 |

#### 布林带参数
| 参数 | 默认值 | 范围 | 步长 |
|------|--------|------|------|
| 周期 Period | 20 | 5 ~ 100 | 1 |
| 标准差倍数 K | 2.0 | 1.0 ~ 4.0 | 0.1 |
| 均线类型 | SMA | SMA/EMA | 切换 |

#### ATR 参数
| 参数 | 默认值 | 范围 | 步长 |
|------|--------|------|------|
| 周期 Period | 14 | 2 ~ 50 | 1 |
| 平滑方式 | SMA | SMA/EMA/WMA | 切换 |

### 3.4 图表面板（主区域）

#### 视图模式（Tab 切换）
| Tab | 内容 |
|-----|------|
| K线 | K线 + 成交量 + 均线 (MA5/MA20) |
| RSI | K线 + RSI 双面板 |
| MACD | K线 + MACD 三面板 |
| 布林带 | K线 + 布林带 + 带宽宽度 |
| ATR | K线 + ATR 双面板 |
| 全部 | 四个指标自上而下排列（小图） |

#### 交互功能
- 鼠标悬浮显示十字准星 + 数据详情
- 底部时间轴滑块缩放
- 图/表切换按钮（看图/看精确数值表）

### 3.5 指标计算引擎 (JavaScript)

使用 ES6 class 封装，每个指标独立模块：

```javascript
class TechnicalIndicatorEngine {
  computeRSI(data, period) { ... }
  computeMACD(data, fast, slow, signal) { ... }
  computeBB(data, period, k) { ... }
  computeATR(data, period) { ... }
}
```

所有计算在 `requestAnimationFrame` 中完成，避免卡 UI 线程。

## 4. 数据流

```
┌──────────┐    ┌──────────────┐    ┌──────────────┐
│ preload   │    │  Parameter   │    │  ECharts     │
│ JSON/CSV  │───→│  + Indicator │───→│  Render      │
│ data      │    │  Engine     │    │  (reactive)  │
└──────────┘    └──────────────┘    └──────────────┘
                      ↑
                用户交互事件
              (股票切换/滑块拖动)
```

### 4.1 数据格式 (预加载 JSON)

```json
{
  "stocks": {
    "002594.SZ": {
      "name": "比亚迪",
      "market": "SZ",
      "daily": [
        {"date": "2025-07-06", "open": 88.18, "high": 89.63, "low": 87.79, "close": 88.17, "volume": 34352802}
      ]
    }
  }
}
```

### 4.2 状态管理

```javascript
const appState = {
  stock: '688981.SH',
  dateRange: { start: '2025-07-06', end: '2026-07-06' },
  viewMode: 'rsi',
  params: {
    rsi: { period: 14, overbought: 70, oversold: 30 },
    macd: { fast: 12, slow: 26, signal: 9 },
    bb: { period: 20, k: 2.0, maType: 'sma' },
    atr: { period: 14, smooth: 'sma' }
  }
};
```

## 7. 扩展预留

- **多股票对比**: 后续可增加"添加对比股票"功能，在图上叠加显示
- **指标叠加**: 允许在一个图上叠加多个指标（如 K线+RSI+布林带）
- **策略回测**: 基于指标信号生成买卖点标记
- **数据导出**: 将计算后的指标数据导出为 CSV
- **WebSocket 实时行情**: 连接 Tushare MCP 推送实时数据
